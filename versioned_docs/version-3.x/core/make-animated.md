`makeAnimated` function takes any component and make it animatable which can read Animated Values.

## Arguments

#### `Element` [ Element ]

It takes an any element argument and make it animatable.

## Returns

It returns an animated component.

## Example

```jsx
const AnimatedH1 = makeAnimated('h1');
```
