The `focus` prop animates on focus/blur: the keyboard/assistive-tech
equivalent of `hover`.

## Usage

```jsx
import { animate, withSpring } from 'react-ui-animate';

<animate.input
  type="text"
  focus={{
    scale: withSpring(1.02),
    borderColor: withSpring('#3399ff'),
    boxShadow: withSpring('0 0 0 3px rgba(51, 153, 255, 0.1)'),
  }}
  style={{ border: '2px solid #e1e1e1', outline: 'none' }}
/>
```

If you set `outline: 'none'` (as above, to replace the browser default with
your own), the `focus` animation *is* the focus indicator. Don't remove
one without providing the other, or keyboard users lose all focus feedback.

## Combining with hover

```jsx
<animate.button
  hover={{ scale: withSpring(1.1) }}
  focus={{ scale: withSpring(1.05), boxShadow: withSpring('0 0 0 3px rgba(51, 153, 255, 0.3)') }}
>
  Accessible Button
</animate.button>
```
