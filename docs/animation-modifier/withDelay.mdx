`withDelay` is a pause, one step you place inside a
[`withSequence`](./withSequence), not a wrapper around another animation.

## Signature

```ts
function withDelay(ms: number): Descriptor;
```

## Usage

```jsx
import { useValue, withSequence, withDelay, withSpring, animate } from 'react-ui-animate';

function Delayed() {
  const [x, setX] = useValue(0);

  const run = () => {
    // highlight-start
    /* Pause 500ms, then spring — withDelay is a sequence step */
    setX(withSequence([withDelay(500), withSpring(200)]));
    // highlight-end
  };

  return <animate.div style={{ translateX: x }} onClick={run} />;
}
```

For staggering several items rather than delaying a single sequence, use
[withStagger](./withStagger) instead. It wraps this same pattern per index.
