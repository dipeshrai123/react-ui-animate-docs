`withSequence` chains animation steps, each starting only after the previous
one completes — for multi-phase motion a single spring/timing can't express.

## Signature

```ts
function withSequence(
  animations: Descriptor[],
  options?: { onStart?: () => void; onComplete?: () => void }
): Descriptor;
```

## Usage

```jsx
import { useValue, withSequence, withSpring, withTiming, animate } from 'react-ui-animate';

function Sequenced() {
  const [x, setX] = useValue(0);

  const run = () => {
    setX(
      withSequence([
        withSpring(100),
        withTiming(200, { duration: 500 }),
        withSpring(0),
      ])
    );
  };

  return <animate.div style={{ translateX: x }} onClick={run} />;
}
```

Steps can mix any driver — `withSpring`, `withTiming`, `withDelay`,
`withDecay` — freely within the same sequence.
