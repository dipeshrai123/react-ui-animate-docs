**React UI Animate** is a lightweight, declarative animation and gesture
library for React. It covers springs, sequences, gestures, and exit animations
with values that update outside React's render cycle.

## Install

Requires React 16.8+ (hooks).

```bash
npm install react-ui-animate@next
```

## Quick example

```jsx
import { animate, useValue, withSpring } from 'react-ui-animate';

function MyComponent() {
  const [width, setWidth] = useValue(100);

  return (
    <animate.div
      style={{ width, height: 100, backgroundColor: '#7d93b0', borderRadius: 4 }}
      onClick={() => setWidth(withSpring(200))}
    />
  );
}
```

`useValue(100)` creates an animated width; `withSpring(200)` animates it.
`animate.div` picks up the change directly, with no re-render involved.
